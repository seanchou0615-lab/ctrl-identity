核心特色

每一項都為了「不干擾遊戲」而設計。

100% 純本機推論

棄用官方 ollama SDK，改以 urllib.request 直連 127.0.0.1:11434，並內建 Proxy 自動繞過。安裝包從 47.4 MB 縮減 18% 至 38.9 MB，無需雲端 API Key。

雙軌防幻覺知識庫

knowledge.json（每日任務、復刻先祖）與 knowledge_base.json（黑話詞典）分離。查無資料時誠實回答「不確定」，升級時不覆蓋你自訂的筆記。

黫㵾海辯論引擎

core/debate.py 依序呼叫三個意識切面，採 ⅔（67%）共識決，單一無效回傳不影響最終採決。

懸浮小球與非干擾 UX

CustomTkinter 340×600 面板與邊緣吸附，Toast 提示 1.5 秒自動消失。使用 overrideredirect + -topmost，嚴禁 focus_force，不搶鍵盤焦點。
